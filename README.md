# winesmaster-assets

Static assets for Wines Master, served through jsDelivr.

## Section headers

18 animated SVG cards (640 x 220) used as the question image on each of the 18 evaluation questions.

URL pattern:

    https://cdn.jsdelivr.net/gh/peterrichardsax/winesmaster-assets@main/section-headers/01-colour-rim.svg

Files: 01-colour-rim, 02-viscosity, 03-aroma, 04-fruit-profile, 05-secondary-notes, 06-body, 07-acidity, 08-dryness, 09-oak, 10-aftertaste, 11-alcohol, 12-blend-or-single, 13-grapes, 14-old-or-new-world, 15-country, 16-region, 17-vintage, 18-rating.

Generated from a small Python script (build_cards.py); regenerate rather than hand-edit.
